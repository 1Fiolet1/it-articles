# Платформа для публикации IT-статей

Приложение для публикации и поиска статей об информационных технологиях. Авторы делятся опытом, разбирают технологии и описывают решения практических задач, а читатели находят полезные материалы по интересующим темам.

Главная идея — создать удобное место для обмена техническими знаниями. Категории и теги помогают ориентироваться в материалах, а поиск — находить нужные статьи.

## Как это работает

- **Опубликуй статью:** зарегистрируйся, добавь заголовок и текст, выбери категорию и теги. После создания статья сразу доступна читателям.
- **Обновляй материалы:** редактируй свои статьи, чтобы исправлять ошибки и дополнять содержание.
- **Выбирай интересующие темы:** просматривай статьи по категориям и тегам.
- **Находи нужное:** используй поиск по ключевым словам.

## Бизнес-логика

### Читатель

- Читает статьи без регистрации.
- Просматривает список публикаций и открывает полный текст.
- Ищет статьи и фильтрует их по категориям и тегам.

### Зарегистрированный пользователь

- Получает все возможности читателя.
- Публикует статьи без предварительного согласования.
- Просматривает свои публикации и редактирует их. Изменять чужие статьи нельзя.

### Статьи, категории и теги

- У статьи есть заголовок, текст, автор, дата публикации, категория и теги.
- Категория задаёт общее направление: например, Backend, Frontend или DevOps.
- Теги уточняют содержание: например, Kotlin, Spring или PostgreSQL.
- При создании статьи проверяется заполнение обязательных полей.

## Серверная часть

Сервер разрабатывается на **Kotlin + Spring** в виде модульного монолита. Основные модули отвечают за пользователей, статьи и справочники категорий и тегов. Для постоянного хранения данных планируется PostgreSQL.

## Идеи для дальнейшего развития

После завершения основной функциональности в планах добавить:

- **Оценки статей** — возможность оценивать полезность материалов и находить публикации с высоким рейтингом.
- **Комментарии** — обсуждение статей, вопросы автору и обмен мнениями.
- **Избранное** — сохранение интересных статей, чтобы вернуться к ним позже.
- **Подписки** — подписка на авторов и уведомления об их новых публикациях.
- **Модерация** — жалобы на публикации и комментарии, проверка материалов, нарушающих правила платформы.
