# Платформа для публикации IT-статей

Приложение для публикации и поиска статей об информационных технологиях. Авторы делятся опытом, разбирают технологии и описывают решения практических задач, а читатели находят полезные материалы по интересующим темам.

Главная идея — создать удобное место для обмена техническими знаниями. Категории и теги помогают ориентироваться в материалах, а поиск — находить нужные статьи.

## Как это работает

- **Опубликуй статью:** зарегистрируйся, добавь заголовок и текст, выбери категорию и теги. После создания статья сразу доступна читателям.
- **Обновляй материалы:** редактируй свои статьи, чтобы исправлять ошибки и дополнять содержание.
- **Выбирай интересующие темы:** просматривай статьи по категориям и тегам.
- **Находи нужное:** используй поиск по ключевым словам.

## Бизнес-логика

### Читатель

- Читает статьи без регистрации.
- Просматривает список публикаций и открывает полный текст.
- Ищет статьи и фильтрует их по категориям и тегам.

### Зарегистрированный пользователь

- Получает все возможности читателя.
- Публикует статьи без предварительного согласования.
- Просматривает свои публикации и редактирует их. Изменять чужие статьи нельзя.

### Статьи, категории и теги

- У статьи есть заголовок, текст, автор, дата публикации, категория и теги.
- Категория задаёт общее направление: например, Backend, Frontend или DevOps.
- Теги уточняют содержание: например, Kotlin, Spring или PostgreSQL.
- При создании статьи проверяется заполнение обязательных полей.

## Серверная часть

Сервер разрабатывается на **Kotlin + Spring** в виде модульного монолита. Основные модули отвечают за пользователей, статьи и справочники категорий и тегов. Для постоянного хранения данных планируется PostgreSQL.

## Идеи для дальнейшего развития

После завершения основной функциональности в планах добавить:

- **Оценки статей** — возможность оценивать полезность материалов и находить публикации с высоким рейтингом.
- **Комментарии** — обсуждение статей, вопросы автору и обмен мнениями.
- **Избранное** — сохранение интересных статей, чтобы вернуться к ним позже.
- **Подписки** — подписка на авторов и уведомления об их новых публикациях.
- **Модерация** — жалобы на публикации и комментарии, проверка материалов, нарушающих правила платформы.

## Реализованные возможности

- регистрация пользователя с сохранением пароля в виде BCrypt-хеша;
- аутентификация через HTTP Basic с загрузкой пользователя из PostgreSQL;
- получение списка категорий и тегов без регистрации;
- создание статьи авторизованным пользователем;
- получение списка статей и отдельной статьи без регистрации;
- просмотр собственных публикаций;
- редактирование статьи только её автором;
- поиск статей по заголовку и содержимому;
- фильтрация статей по категории и тегам;
- проверка входных данных и обработка ошибок;
- защита от одновременного изменения статьи с помощью её версии.

## Запуск приложения

Для запуска потребуются Java 17 и Docker.

### 1. Настроить переменные окружения

В корне проекта нужно создать файл `.env` на основе примера:

```bash
cp .env.example .env
```

Содержимое файла:

```dotenv
DB_NAME=it_articles
DB_URL=jdbc:postgresql://localhost:5434/it_articles
DB_USERNAME=admin
DB_PASSWORD=change_me
```

Значение `DB_PASSWORD` можно заменить своим. Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий.

### 2. Запустить PostgreSQL

Docker Compose поднимает PostgreSQL на порту `5434`:

```bash
docker compose up -d postgres
```

Проверить состояние контейнера:

```bash
docker compose ps
```

### 3. Запустить сервер

Из корня проекта:

```bash
./gradlew :app:bootRun
```

При запуске Flyway автоматически применит миграции, а Hibernate проверит соответствие JPA-сущностей созданной схеме. Hibernate настроен через `ddl-auto=validate` и самостоятельно таблицы не создаёт.

Сервер будет доступен по адресу `http://localhost:8080`.

Swagger UI для ручной проверки API будет доступен по адресу `http://localhost:8080/swagger-ui/index.html`. Для защищённых эндпоинтов нужно нажать кнопку **Authorize** и указать имя пользователя и пароль, использованные при регистрации.

Остановить PostgreSQL можно командой:

```bash
docker compose down
```

## Основные эндпоинты

| Метод и путь | Доступ | Назначение |
| --- | --- | --- |
| `POST /api/users/register` | Публичный | Зарегистрировать пользователя. |
| `GET /api/categories` | Публичный | Получить категории. |
| `GET /api/tags` | Публичный | Получить теги. |
| `GET /api/articles` | Публичный | Получить, найти или отфильтровать статьи. |
| `GET /api/articles/{id}` | Публичный | Получить статью по идентификатору. |
| `POST /api/articles` | HTTP Basic | Создать статью. |
| `GET /api/me/articles` | HTTP Basic | Получить статьи текущего пользователя. |
| `PUT /api/articles/{id}` | HTTP Basic | Изменить свою статью. |

Для списка статей доступны параметры:

- `search` — поиск по заголовку и содержимому без учёта регистра;
- `categoryId` — фильтрация по категории;
- `tagIds` — фильтрация по одному или нескольким тегам. При выборе нескольких тегов возвращаются статьи, содержащие хотя бы один из них.

Пример объединения поиска и фильтров:

```text
GET /api/articles?search=kotlin&categoryId=1&tagIds=1,2
```
